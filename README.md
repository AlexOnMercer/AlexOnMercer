## hi, i'm Alex 👋

Software engineer and full-stack developer. I build backend services and the interfaces on top of
them — and spend my spare time on open-source infrastructure, where the interesting problems live.

- ⚙️ **backend** — Java & Spring Boot, C# & .NET, Python & Django
- 🎨 **frontend** — React with TypeScript
- 🗄️ **data & messaging** — PostgreSQL, Kafka
- 📦 **open source** — co-author of [**SectoriaDB**](https://github.com/api-mayuri/SectoriaDB), an
  S3-compatible object store with its own copy-on-write B+-tree metadata engine
